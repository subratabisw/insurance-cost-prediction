# Medical Insurance Cost Prediction

A Machine Learning project that predicts medical insurance
charges based on personal and health-related features.

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Multiple Linear Regression
- Model Evaluation
- Streamlit Web Application

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Dataset Features
- Age
- Sex
- BMI
- Children
- Smoker
- Region

Target: Charges

## Run Locally

pip install -r requirements.txt

streamlit run app.py
